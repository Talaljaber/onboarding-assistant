# P10.2 — UI declutter ("it feels crowded")

Why: the crowding came from label inflation (each compliance meaning repeated per card, header,
notice and footer, each in its own pill) and from phone chrome. Rule now in `ui/Badge.tsx`: a badge
only for per-item state that changes; each required meaning once per screen; company values as text
with a dot (`ValueTag`); mode, storage and model only in the settings sheet and About; chrome follows
the UI language while K-rows, scenario text and the fixed refusal stay Arabic (`useServerLabel`).

- Header and nav: brand, short role chip (full name in `aria-label`), one-tap language toggle
  (`lang-toggle`), settings. Mode, trace, model and storage status, About and the admin sign-in (or
  the knowledge base) moved into the settings sheet at every width; a dot on the settings button
  marks a forced offline mode. No prototype badge (the footer / phone banner carry the disclaimer,
  now one line). Bottom bar has 5 items (no "More") and hides during practice; 56px header on phones.
- Scenarios: the situation is the card heading, a quiet `S04 · ● value` meta line, the whole card is
  a link, "fictional" stated once in the page description with the practised count; the other track
  is a text link under the list. Chat start card: one meta line (keeps a one-word fictional mention),
  one prompt line; feedback card: one "not an evaluation" caption, no boxed notice, no "Nothing is
  scored" sentence; labels in the UI language.
- Chat: compact source rows (K-id inline before the verbatim row, copy button floated), document and
  page named once per block when shared; mode chip only when it differs from the current mode or
  when offline is forced; grounded note moved to the Sources heading hint; short placeholders;
  counter only past 80%; "New conversation" only when there is a thread; one-line practice bar.
- Plan: "Suggested" badge plus the description (no amber notice); activities as hairline rows
  without type captions; the Day 30 quiz note and the Day 90 note sit on their activity rows; one
  Day 90 summary entry («اعرض ملخص التعلم»); long read lists show a count.
- Progress: one hero card (ring, "1 of 8 activities", the not-a-score caption, quiz row), a compact
  milestone summary linking to the plan (no second checklist), reset as a muted footer row.
- Quiz: no "ordered by track" badge; disabled primary buttons turn grey. KB: one "Admin mode" badge,
  no "Official" badge on default rows (`data-status` kept), edit action in the row's top line, source
  line hidden on phones, h1 follows the tab, "Manager view (demo)" tab, one manager notice line.
  About: three section cards, shorter title, storage shown with the server status. Welcome: tile
  hints describe the track. Badge `sm` is 12px, medium weight.
- Tests updated (shell, chat, scenarios, plan, progress, kb, quiz, about) plus new ones; e2e step 20
  opens the settings sheet at every width, step 12 clicks «اعرض ملخص التعلم»; `ui_shots.py` sets the
  trace through the settings sheet. Not touched: manager "0% progress" (backend data, separate task).
