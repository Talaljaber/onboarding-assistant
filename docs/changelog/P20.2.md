# P20.2: practice and checkpoint quizzes (web)

Built on the P20.1 contract (`web/src/api/types.ts`, `client.ts`; merged from `p20/api`).

## Intern (`#/quiz`)
- The Quiz screen is a list (`components/quiz/QuizList.tsx`): «الاختبار التدريبي الرسمي» first (always open), then the
  published sets for this intern (`GET /api/quiz-sets?profile_id=`): title (English when authored), N questions,
  «مفتوح» or a lock with «يفتح عند وصول تقدمك في الخطة المقترحة إلى 30%». Practice cards carry «للتعلّم فقط: لا
  تُعرض إجاباتك أو نتيجتك على المشرف.»; checkpoint cards the badge «تُشارك النتيجة مع مشرفك». If the list cannot load,
  the official quiz is still offered.
- `#/quiz?set=<id>` takes one quiz (`QuizRunner.tsx`, the existing flow): the official quiz keeps its role order, the
  browser practice record and the Day 30 plan tick; a set loads `GET /api/quiz-sets/{id}` (400 field `progress`
  `reason:locked:<pct>` → «هذا الاختبار لم يُفتح بعد» with the share; 404 → not available).
- Checkpoint sets: before the first question a notice that must be acknowledged with «ابدأ»; the end card shows
  «نتيجتك المُشارَكة مع مشرفك: 4 / 5» on the first attempt and marks later attempts as practice.
- «أعد المحاولة» puts the questions missed last time first (adaptive retry).
- After a wrong answer «اسأل مشرفي عن هذا» opens the existing confirm sheet (source `quiz`, text «<question> (K07)»,
  editable; nothing sent before Send). The questions UI labels the source «من اختبار» / "From a quiz".

## Admin («الاختبارات», `#/admin/quizzes`, `#/admin/quizzes/:id`)
- Nav item in the admin shell (tab row below lg, header from lg; header pills drop their icons and padding below xl
  so four items and the open-questions count fit beside the brand at 1024 px).
- Sets list: the official quiz (read only, question and practice counts, its content signals), then each set with
  draft/published, «نقطة تحقق», audience, «يفتح عند تقدم N%», question count and "practised by N"; «اختبار جديد».
- Set editor: publish switch (an empty set says to add a question first), settings (titles, mode practice /
  checkpoint — 400 field `mode` once answered is explained, audience everyone / a track / chosen active interns,
  opens-at slider + number), questions (up/down, edit, delete with confirm), add/edit dialog (K-row picker with the row
  verbatim, question, three options, correct radio, «صياغة مسودة بمساعدة الذكاء الاصطناعي» → the verified draft fills
  the form labelled «مسودة من النموذج — راجعها قبل الحفظ», 503 `llm_unavailable` / `draft_failed` explained; grounding
  failures inline per field from `reason:<code>[:<n>]`, e.g. «الرقم 30 غير موجود في الصف K02.»), CSV upload with a
  template download and the per-line result, checkpoint results (table from sm, cards on phones; «لم يبدأ»), and the
  content-signals panel «إشارات المحتوى — ليست تقييماً للأداء» ("—" and «يظهر بعد أن يجربه 3 متدربين على الأقل»).
- Intern detail: a «نقاط التحقق» card with each checkpoint's first-attempt result (only when the detail carries it).
