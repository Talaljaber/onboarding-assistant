# P14.1 — Answer Recall «استدعاء الإجابة»

«إذا تغيّر مصدر إجابة، يظهر عند كل من تلقّاها تنبيه بما تغيّر بالضبط.» When a K-row changes, a saved answer
built on it is flagged in the intern's own browser with the exact change.

## What

- **1a. Recall in the browser.** `web/src/components/chat/useKbWatch.ts` reads the open `GET /api/kb` on mount,
  on window focus and every 15 s, and publishes a new live KB only when `version` changed.
  `web/src/components/chat/recall.ts` (pure) compares every saved `sources[].answer_ar` with the live row:
  `same`, `changed` or `removed`, ignoring diacritics, tatweel and whitespace runs (the `app/textnorm.py`
  mark set); `wordDiff` is a word-level LCS diff that shows only verbatim row text (removed words from the
  saved text, added words from the live row). A changed answer (answer, partial, related row, employment
  rows) gets an amber frame with «تغيّر مصدر هذه الإجابة بعد أن تلقيتها», the time it was received, the diff
  per row (~~17~~ **18**, `<del>`/`<ins>` with screen-reader labels) or «لم يعد هذا المصدر موجوداً», and
  «أعد السؤال», which resends the user text right before that reply with `last_user_message: null` as a new
  question. A KB reset (every row official again) clears every recall. `ReplyItem` gains optional `at` (ISO)
  and `kbVersion`, saved and accepted by `loadItems`; old threads without them still load.
- **1b. Ask-again hint on refusals.** `kbVersion` comes from `trace.retrieval.kb_version`, else the watcher's
  last version. An `out_of_scope` refusal shows «أُضيفت مصادر جديدة بعد هذا الرد — أعد السؤال» with the
  re-ask button when the live version differs from the item's and the live KB has an `added` row. Guard
  refusals (contact, injection, employment) never show it. No new endpoint.
- **1c. Admin impact line.** `GET /api/admin/kb/{id}/impact` (admin only; `{id}` checked with `KB_ID_RE` and
  the live KB, else 404) → `KbImpact {id, interns: InternPublic[], activity_ids[], quiz_ids[]}` from
  `app/kb_impact.py`: interns whose linked profiles have turn logs citing the row (`Store.activity`, ids only;
  works on LocalStore and SupabaseStore alike), plan activities whose refs hold it and quiz items explained
  by it. `RowDialog` in edit mode shows «استُشهد بهذا الصف في إجابات لـ 1 متدرب (سارة الخطيب)» and the pitch
  line before saving; nothing while loading, on failure or with no intern (never "0").
- Contract triplet: `app/schemas.py` (`KbImpact`), `web/src/api/types.ts` (`KbImpact`, `isKbImpact`),
  `web/src/api/client.ts` (`getKbImpact`), `contracts/fixtures/kb_impact.json` + `INDEX.md`,
  `docs/api_contract.md` §6f, `tests/test_contract.py`. i18n block `recall` at the end of `ar.ts`/`en.ts`.
- `tests/e2e/conftest.py`: `E2E_PORT` overrides the port (default still 8010).

Not changed: agent, router, guards, prompts, `textnorm.py`, migrations. No chat text is stored anywhere new.

## Tests

- `web/src/components/chat/__tests__/recall.test.ts`: 17 → 18 gives one removed and one added token;
  diacritics/tatweel-only differences give no diff; same / changed / removed; reset clears; the hint rule.
- `web/src/components/chat/__tests__/recall.chat.test.tsx`: a version change turns the K02 card amber with the
  diff; «أعد السؤال» sends the preceding user text with `last_user_message: null`; poll noise changes nothing;
  reset clears; removed row; `at`/`kbVersion` saved and loaded, old threads still load; the hint only on the
  out-of-scope refusal and only with an added row.
- `web/src/components/kb/__tests__/impact.test.tsx`: the impact line (Arabic and English names), nothing on
  empty or failure, no call in add mode.
- `tests/test_kb_impact.py`: a real K02 turn lists Sara (anonymous turns count for nobody); plan and quiz refs;
  401 without the admin token; 404 for unknown or malformed ids; SupabaseStore over `httpx.MockTransport`
  equals LocalStore.
- `tests/e2e/test_recall.py` (both viewports): Sara asks «كم عدد المعارض؟» → admin edits K02 to 18 and sees
  Sara in the impact line → Sara signs out and back in and sees the recall and diff → re-ask cites the edited
  K02 → reset clears.
