### P5.1, P5.3–P5.5 — Hardening, tripwire, performance and the security review  (Opus 5.5, 2026-11-11)
- What now exists: startup validation with a one-line fix and exit 1 (bad env value, unpinned or
  malformed `LLM_MODEL`/`LLM_ESCALATION_MODEL`, `openrouter/...` auto-routing, bad `LOG_LEVEL`/`PORT`/deadlines,
  missing encoder, official sha mismatch, unloadable `data/ours` CSV) for uvicorn and `python -m app`;
  security headers on every response (nosniff, no-referrer, `X-Frame-Options: DENY`, self-only CSP);
  cross-origin writes refused; `/api/health?probe=1` throttled to one LLM probe per 10 s; an offline turn
  caused by a down LLM (e.g. exhausted budget) names the reason in `trace.agent.fallback_reason`;
  `.env.example` lists every setting; `smoke_api.py --serve --offline` runs the server itself under the
  network tripwire and fails on any swallowed attempt, `--session N` repeats the storyboard for N s;
  `serve_check.py` prints the cold-start time; `docs/perf.md`; `docs/security_review.md` (20 findings).
- Interfaces added/changed: `app.config.check_model_id`, `settings_error`, `MODEL_ID_RE`; `get_settings()`
  raises `StartupError` instead of `ValidationError`; `app.main.main_app()`; `app.api.SECURITY_HEADERS`,
  `CSP`, `PROBE_MIN_INTERVAL_S`, `cross_origin()`, `explain_offline()`. Settings bounds: `PORT` 1–65535,
  `LLM_DEADLINE_S`/`LLM_AGENT_DEADLINE_S` in (0, 60], `LLM_MAX_RETRIES` 0–3, `LLM_BUDGET_USD` ≥ 0.
- How to use it: `& $VPY scripts\no_network.py scripts\smoke_api.py --serve --offline [--session 60]`;
  `$env:DADA_PYTHON=$VPY; & $VPY scripts\serve_check.py`.
- Config/env: new lines in `.env.example` (`LLM_AGENT_DEADLINE_S`, `LLM_CACHE_PATH`, `LLM_BUDGET_PATH`,
  `ENCODER_DIR`, `DATA_OFFICIAL`, `DATA_OURS`, `DATA_LIVE`); no new variables.
- Acceptance: `pytest -q` → 639 passed; ruff + mypy clean; tripwire smoke → `demo sequence OK (offline)`,
  `tripwire: 0 network attempts by the server` (60-s session: 65 rounds); `serve_check.py` → status ok,
  cold start 8.0–8.7 s; `check_web.py` → OK; offline answer p50 10.7 ms / p95 13.6 ms over DEV;
  Chromium over 8 routes with the CSP: 0 violations.
- Limitations / TODO: staff mode has no auth (demo limitation); DNS rebinding, row/rate caps and log
  rotation recorded, not fixed; LLM p50/p95 left as placeholders in `docs/perf.md` for the integrator;
