### P8.2 — answer panel (small model first, reasoning model when needed)  (Opus, 2026-11-11)
- What now exists:
  - `app/llm/panel.py`: `run_panel(question, rows, ranks, chat, escalation, settings, budget_s, *, previous=None,
    band=None) -> PanelOutcome`; `PanelSettings(accept=0.7, sanitizer_s=1.5, answer_s=3.0, judge_s=2.0,
    escalation_s=6.0, escalation_min_s=2.5)`. Sanitizer ∥ answerer (threads) → verifier → citation judge ∥ coverage
    judge → accept (both ok and min confidence ≥ accept) or escalate once (reasoning model, judges' notes as DATA)
    → verifier → else the verified flash draft → else None (offline). Every stage failure = low confidence.
  - Prompts `prompts/panel_{sanitizer,citation,coverage,escalate}_v1.md` (English rules, YAML version, JSON data
    blocks, strict JSON out). `answer_v1.md` is unchanged and is the answerer's prompt.
  - Deterministic list fix (`tools.answer_from_rows`): the chooser's `list_topic` is honoured only when
    `retriever.is_list_question(message)`; «هل النزاهة من قيم الشركة؟» answers K05 alone.
- Interfaces added/changed:
  - `answer.answer_llm(..., band=None)`; panel runs when `llm.panel` is set and there is no list topic (a list
    question keeps one call with the server list first, `trace.panel.single_call = true`). `AnswerResult.panel`,
    `info["panel"]` (only when the panel ran), `ToolResult.panel` → `Trace.panel`; steps `panel:accepted|escalated|draft|single_call`.
  - `LLM.panel: PanelSettings | None`; `build_llm` builds the escalation `CachedChat` with
    `extra_params={"reasoning": {"enabled": True}}`, `max_tokens=2000`.
  - `OpenRouterClient.chat`: a `reasoning` entry in `params` replaces the reasoning-off default (provider
    `data_collection: deny` always sent). `CachedChat.last_error` is per thread (panel stages run in parallel).
  - `Budget` price table: `z-ai/glm-5.3` $0.07 / $1.40 per Mtok (usage.cost preferred).
  - `agent.PANEL_TURN_BUDGET_S = 9.0` when the panel can run; otherwise `LLM_DEADLINE_S` (5 s).
- How to use it: nothing to call; `LLM_PANEL=1` (default) routes knowledge answers through the panel.
  Per knowledge turn without cache hits: 1 tool choice + 4 flash (sanitizer, answerer, citation, coverage) = 5
  flash calls; +1 flash when the sanitizer flags and cleans the question; +1 GLM call when not accepted or the
  draft failed verification. Unsupported draft: no citation judge (4 flash). List questions: 2 flash.
- Config/env: `LLM_PANEL` (default 1), `LLM_PANEL_ACCEPT` (default 0.7; pick on DEV), `LLM_ESCALATION_MODEL`
  default `z-ai/glm-5.3` (empty = no escalation). `.env.example` updated.
- Acceptance: `pytest -q` → 669 passed; `ruff check app scripts tests` → All checks passed!; `mypy app` → Success
  (32 files); `no_network.py run_eval.py --set dev --mode offline` → gates PASS, DEV offline 106/154 (unchanged).
