# P13.3: phone layout of the P13 screens and Word headings in any language

- Coverage card header no longer squeezes its description at 360 px (shared `Card` header lets the title
  block wrap above the actions); request status labels stay on one line; coverage row links and request
  Edit/Delete meet the 44 px touch target on phones. Checked at 360/390/768 px in Arabic and English with no
  horizontal overflow.
- Word import: headings are now recognised by the style's stored name (and outline level) from
  `word/styles.xml`, not only by its id. Word in Arabic (and other UI languages) saves "heading 1" under a
  localised id such as "1", so headings were missed and a whole page became one passage.
  Test: `test_docx_headings_saved_by_word_in_another_language`.
