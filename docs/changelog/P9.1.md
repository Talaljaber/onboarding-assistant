# P9.1 — UI redesign foundation

- `docs/UI_PLAN.md`: audit of the before shots, design direction, tokens with contrast ratios,
  component specs, per-screen change list and the work split for P9.2 to P9.4.
- Tokens: warm ivory neutrals, deep teal `#0b6457` (7.1:1 on white), amber highlight, new soft tints,
  radius xl, `shadow-3`, easing and layout tokens. Light only; the token contrast test still passes.
- Primitives restyled with backward-compatible APIs; new props (Button `soft`/`lg`/`icon`/`block`,
  Card `variant`/`icon`/`description`/`level`, Dialog `size` and phone bottom sheet, IconTile `size`/
  `chevron`, EmptyState `icon`, Badge `size`) and new `Page`, `PageHeader`, `Notice`, `StatTile`,
  `ProgressBar`, `recipes.ts`; icons `settings`, `arrow-end`, `chevron-end`, `sparkle`, `calendar`, `target`.
- Shell: 64px header with an original mark; inline controls from 1280px, settings sheet below; icon
  rail at md, labelled sidebar from lg, bottom bar with safe-area padding on phones.
- Welcome screen redesigned (hero, raised role panel, promise rows).
- i18n: `uiShell` block plus empty `uiChat`, `uiLearning`, `uiAdmin` blocks for the screen workers.
- `scripts/ui_shots.py`: screenshots at 360/390/768/1280 into `docs/screenshots/after/`, fails on
  horizontal overflow.
