### P14.4 — number highlight in the cited row  (2026-11-12)
- What now exists:
  - `web/src/lib/highlight.ts` (pure): `numbersIn(text)`, `asciiDigits(text)`, `highlightSegments(text, numbers)`
    and `highlightNumbers(row, answer)`. Digit runs only (ASCII, Arabic-Indic U+0660–0669 and extended
    U+06F0–06F9, compared as ASCII without leading zeros); whole numbers only, so «1» never marks the 1 in
    «1991». The pieces join back to the row verbatim. The Rumour Check `differs` card can mark a row's number
    with `highlightSegments(row, [n])`.
  - `SourceRow` takes an optional `answer`; `SourcesBlock` passes it on; `AnswerCard` passes `reply.text_ar`.
    Each matching number renders in a `<mark data-num-mark>` (amber tint). Copy still copies the plain row.
- Interfaces: client only, no contract change. Not used on refusal, employment or not-confirmed cards (their
  texts are fixed and carry no row numbers).
- Acceptance: `src/lib/__tests__/highlight.test.ts` (match, no match, whole numbers, Arabic-Indic digits, direct
  numbers); chat test: the offline K14 answer marks exactly «90» and the row text stays verbatim.
- Integrator: demo shot 2 («متى تأسست مجموعة الدادا؟») should show 1991 marked in K01, in both modes.
