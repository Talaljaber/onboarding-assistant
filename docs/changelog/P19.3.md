# P19.3: admin screens on phones and tablets

Owner: "check the mobile responsiveness of the newly added things" (after the P19.1 rebrand). Admin side, walked
at 360, 390, 414, 768, 1024 and 1280 px in Arabic and English with a real browser.

- «أسئلة المتدربين»: on a phone the four status filters sit in a 2 x 2 grid. The pill row scrolls without a
  scrollbar, and in English at 360–414 px «All» (and part of «Closed») was hidden past the edge with no cue.
- Interns list: the cards (with the same counts) are used below 1024 px, two per row from 640 px; the nine-column
  table squeezed English names word by word at 768 px and scrolled inside its card. In the table a name or track
  wraps only between words ("Sara" / "Al-Khatib", never "Al-" / "Khatib") and the status badge never wraps
  («Not started» took two lines at 1024 px). The card's name link is a 44 px tap target (it was 24 px).
- Email log: an address breaks only after the "@" (the table column was a sliver with a line per 3–4 letters);
  a phone shows the newest 5 emails and «اعرض كل الرسائل (n)» / "Show all n emails" opens the rest (up to 50
  cards made the interns screen several screens long).
- KB coverage card: the K-id links are 44 x 44 on phones (they were 25 px wide).
- i18n: `mail.showAll` (ar + en). Tests: questions filters grid, interns card link and name wrapping, email
  address break and phone preview, coverage link size.
- Checked and unchanged: the answer dialog in both modes (long text, keyboard-sized viewport: the sheet scrolls
  and the send button stays reachable), dismiss and the toasts, add / edit intern with a valid, invalid and
  cleared email, new request (one intern / the track), the admin request thread with files, the KB editor
  (K02, «جرّب الآن», restore), document import and review.
- Not in this area (reported to the shell owner): the admin header overflowed at 768 px (sign-out and the
  language button off-screen, the questions badge hidden in English).
