# P22.1 — intern-side browser QA fixes

Browser pass (Playwright, chromium) as Sara (Sales), Omar (Delivery) and Layan (Sales, not in a chosen-interns set) at
360×800, 390×844, 768×1024, 1280×900 and 360×440, Arabic and English, against an offline local server seeded through
the API. Fixes (web only, no contract change):

- Checkpoint quizzes: the intern's shared result from the server (`my_result`) now shows on the quiz card ("2 / 3", or
  how many are answered so far) and above the questions when a checkpoint answered before is reopened (after a reload
  or on another device), with "this attempt is practice". Before, it showed only on the end card of the same visit.
- Quiz hand-offs (owner): «اسأل المساعد عن هذا السؤال» and «اسأل مشرفي عن هذا» now carry the question, its three
  options and the intern's pick («سؤال من الاختبار: … الخيارات: أ) … ب) … ج) … — اخترتُ: أ», the mentor's text ends
  with the K-id), at most 600 characters, in the UI language.
- Chat dock: the «من مشرفك» / «أسئلتك لمشرفك» scroll boxes are positioned, so their visually hidden radios no longer
  add a long blank scroll area below the page.
- Mentor requests: inside each open status the nearest deadline comes first (overdue, due soon, later, none).
- Send-to-mentor line: a question the mentor already answered says «أجاب مشرفك عن هذا السؤال…» instead of "the answer
  will appear".
- About › what is stored: says practice answers and results are not shown to the mentor (counts only) and that a
  checkpoint shares first answers (new key `p22Intern.storedText`).
- Progress: the quiz line is labelled «الاختبار التدريبي الرسمي» (only the official quiz is recorded there).
- `questionCount()` in `web/src/lib/format.ts`: zero reads «لا أسئلة» / "No questions" (the admin quiz list still
  calls the plural keys directly; it can switch to this helper).

New i18n block `p22Intern` at the end of both dictionaries. Tests: web vitest (quiz, requests, about).
