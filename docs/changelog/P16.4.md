# P16.4 — UI polish from the UI/UX and journey audits

Web client only; no API, contract or server change.

- Trace «لجنة التحقق» (U2, U3, journey B10): no fixed minimum width inside a horizontal scroller (it
  clipped the start of each line in RTL at 360/390 px); lines wrap. Each vote shows a short fixed
  summary in the UI language built from its role, verdict and the server's note prefixes
  (`flags: …`, `discarded: …`, `refusal kept: …`); the model's own note (often English) is behind
  «تفاصيل تقنية».
- Admin intern timeline (U4): an activity event shows the activity title with its id as a small tag;
  the newest 15 events, then «عرض المزيد (n)».
- KB table and KB coverage card (U5): the English keyword is no longer a visible heading (it went stale
  after an edit, «17 showrooms» after 17 → 18); the coverage rows show the topic. Official topics are
  Arabic in the Arabic UI (Company → الشركة, Values → القيم, Onboarding → التهيئة, Policy → السياسات;
  any other topic as it is). Same topic names in the mentor-request card and the intern detail.
- Mentor request dialog (journey B7, #11): the row picker reads «K02 · الشركة · start of the row
  text…»; «في مسار مسار المبيعات» → «في مسار المبيعات» (and "on the Sales track track" in English).
- Sign-out toast (U10): shown after the route change (the route effect used to drop it at once); intern
  header and admin shell.
- «جرّب الآن» (U11): «استعادة النسخة الرسمية» clears the stale answer.
- Mentor request marked «تم» (U13): a short confirmation toast; the panel stays open so the card stays
  visible in its done state (one line in the panel's status handler, no layout change).
- Day-90 summary and progress dates (U14): the local calendar day, not the UTC one.
- Import (U15, journey #15): the type list is an LTR isolate so the dots sit before each extension;
  the document name is required and pre-filled with a readable title: a .txt/.md file's own heading
  (first short line that is not a sentence), else the file name with filler words such as "doc",
  "final", "v2" dropped, camelCase/dashes split and the first letter upper case; the help text asks
  for a clear title. Toast grammar: «أُضيف صف واحد», «أُضيف صفّان», «أُضيفت 3 صفوف», «أُضيف 11 صفاً»;
  same agreement for «أُرسل الطلب إلى …», «… مرة» (scenario count, coverage) and the coverage tiles
  («4 أسئلة» instead of «4 سؤالاً», «… رسائل في المجموع»).
- English "1 times" (U16) → "1 time". Character counters (U17) all read «{n} من {max}» / "{n} of {max}".
- Demo-banner close button (U18): «إخفاء التنبيه» / "Hide this notice".
- Chat error card (I3): the retry button sits under the message on phones.
- Import review header (I7): a no-break space keeps «ص»/«م» with its time (all `formatWhen` dates).
- Tests: vote summaries and the note disclosure, timeline titles and paging, plural forms, topic names,
  local day, AM/PM no-break space, readable document names; counter strings updated.
