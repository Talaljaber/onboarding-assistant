## Changes
- `app/llm/panel.py`: escalation runs on the stage pool so its wall-clock deadline holds (the provider's
  keep-alive bytes reset httpx's read timeout; escalated turns took up to 20 s). A late verified reply is
  cached and used on the next identical turn.
- `app/llm/panel.py`: an "unsupported" flash draft is kept (no judges, no escalation) unless the
  deterministic retrieval band is "answer". A coverage-judge hint had talked GLM into answering a question
  the rows do not answer.
- `app/llm/__init__.py`: `ESCALATION_PARAMS = {"reasoning": {"effort": "low"}}`.
- `prompts/panel_citation_v2.md`: a sentence that adds a fact the question did not ask about is not ok.
- `prompts/panel_escalate_v2.md`: answer only what is asked; a missing specific value (phone, address,
  name, price) is unsupported; a conditional rule about an unnamed case is partial with the condition quoted.
- `scripts/check_ours.py`: refuses to open either sealed held-out file.

## Threshold
`pick_panel.py` on the v3 run: every judge confidence was ≥ 0.85, so any ACCEPT in 0.50–0.85 gives the same
result. Kept the default 0.7.
